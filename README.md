# 具身智能市场研究

这是一个持续更新的具身智能行业研究网站，集中整理机器人公司、产品与技术路线、商业落地、行业资讯和资本市场动态。网站内容基于公开资料，用于行业观察与研究参考。

访问网站：<https://hongzy7.github.io/embodied-market-research/?v=20260917>

## 网站内容

- **首页**：展示网站的研究范围、公司数量与各研究栏目的入口。
- **战略坐标**：从平台化能力与商业成熟度等维度观察代表性公司，并展示尚待补充评分的公司清单。
- **公司情报库**：汇总具身智能产业链相关公司与机构，可按关键词、地区、细分领域和成熟度进行搜索与筛选。
- **7轴竞品雷达**：对比七轴人形手臂产品的关键参数、应用方向及厂商信息，并跟踪产品、成交、交付和落地信号。
- **每日动态**：按日期整理人形手臂与具身智能领域的重要资讯，提供摘要、关键词、核心要点和公开来源。
- **资本动态**：跟踪重点机器人公司的股票市值、行情表现及融资、上市和投资等资本事件。

网站会随公开信息持续补充和更新。行情及研究资料可能存在延迟，仅供研究参考。
