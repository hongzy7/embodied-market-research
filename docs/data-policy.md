# 公开数据规范

## 可以提交

- 企业官网、公开新闻、公开融资和产品信息。
- 带来源链接的研究结论。
- 已确认拥有使用权的 Logo、图片和视频。
- 不包含内部判断的公开版日报 JSON。

## 禁止提交

- 飞书 Base 记录链接、内部记录 ID 或访问凭据。
- 客户备注、联系人、手机号码、跟进状态和合作优先级。
- 内部报价、未公开商务策略和 `*.internal.md` 报告。
- API token、cookie、密码、`.env` 文件或其他密钥。

## 更新检查

新数据提交前运行：

```bash
pnpm validate
pnpm build
```

自动校验是最低防线，不能替代对来源、版权和公开边界的人工审查。
